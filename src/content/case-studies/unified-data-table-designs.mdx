Tables in iCE were never standardized and it has always been a point of frustration for users, engineers and me, the only designer.

I found 4 (sort of 6) different table design systems and proposed a new design system for the tables that would finally rid us of this eternal design debt. I added to the component library a reusable component in Figma for users to build any required table. This also gave a source of truth for all tables in the product.

## Visualizations in the table, addition by subtraction!

I stripped out a few peculiarities to how data was visually displayed:

- Pills that reach their maximum when the value reaches 50%
- Overlaying values on the pills
- Simplifying colour range
